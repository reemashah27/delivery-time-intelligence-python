# Delivery Time Intelligence Using Python

## 📌 Project Overview

Delivery Time Intelligence is a Data Analytics and Machine Learning project developed using Python.

The project analyzes e-commerce delivery data to understand the factors affecting delivery time and delivery delays. It also uses Machine Learning to predict delivery time.

## 🎯 Objectives

- Analyze e-commerce delivery data
- Perform data cleaning and preprocessing
- Perform Exploratory Data Analysis (EDA)
- Analyze traffic, weather, distance, city and delivery partner factors
- Create meaningful data visualizations
- Predict delivery time using Machine Learning
- Evaluate model performance
- Identify important features affecting delivery time

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Dataset

The project uses a simulated e-commerce delivery dataset containing 1,500 orders.

The dataset contains delivery-related information such as traffic, weather, distance, city and delivery partner information.

## 🔍 Project Workflow

1. Data Loading
2. Data Quality Checking
3. Data Cleaning
4. Exploratory Data Analysis
5. Feature Engineering
6. Data Visualization
7. Machine Learning
8. Model Evaluation
9. Feature Importance Analysis
10. Business Insights

## 🤖 Machine Learning

A Random Forest Regression model was used to predict delivery time.

The model was evaluated using:

- MAE
- RMSE
- R² Score

## 📈 Key Analysis

The project explores how delivery time is affected by:

- Traffic conditions
- Delivery distance
- Weather conditions
- City
- Delivery partner
- Other delivery-related factors
